📄 Description du projet : Football Club Management System

Ce projet est un système de gestion d’un club de football développé dans le cadre du module Systèmes d’Exploitation. Il permet de mettre en pratique plusieurs concepts importants comme l’automatisation, la gestion des processus, les bases de données et la conteneurisation.

⸻

🎯 Objectif du projet

L’objectif principal de ce projet est d’appliquer des notions vues en cours, notamment :

* La gestion des processus (ordonnancement CPU)
* L’automatisation des tâches sous Linux
* La gestion de bases de données
* L’utilisation de Docker pour la conteneurisation
* Le développement de scripts et programmes en Python et Bash

⸻

🧰 Technologies utilisées

* 🐍 Python : implémentation des algorithmes d’ordonnancement (Round Robin et SRTF)
* 🐚 Bash : création d’un système de gestion des joueurs en ligne de commande
* 🐳 Docker : déploiement de la base de données MySQL dans un conteneur
* 🗄️ MySQL : stockage et gestion des données des joueurs
* 💻 Git & GitHub : gestion de versions et hébergement du projet

⸻

⚙️ Fonctionnalités

* Ajouter un joueur
* Afficher la liste des joueurs
* Supprimer un joueur
* Rechercher un joueur
* Gestion des données via MySQL
* Simulation des algorithmes d’ordonnancement CPU

⸻

🧪 Algorithmes d’ordonnancement

1. Round Robin

Algorithme qui attribue un temps d’exécution fixe à chaque processus de manière cyclique.

2. SRTF (Shortest Remaining Time First)

Algorithme qui sélectionne le processus ayant le temps d’exécution restant le plus court.

⸻
2. Exécuter le script Bash :
bash bash.sh

3. Exécuter le programme Python :
   python scheduling.py


Conclusion

Ce projet permet de comprendre le fonctionnement des systèmes d’exploitation à travers la gestion des processus, l’automatisation et la manipulation de bases de données. Il offre une expérience pratique complète sur les outils utilisés en informatique moderne.
